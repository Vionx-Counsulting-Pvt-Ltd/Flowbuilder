name: Workflow shortcut navigation
description: Personal request tables and in-page creation from dashboard workflow shortcuts.
---

Dashboard workflow shortcuts are for submitting and following the signed-in user's requests, not for opening the builder or the generic workflow catalog.

**Why:** The owner requested a workflow-specific table of the user's requests, clickable request details, and a New request popup on that same page.

**How to apply:** Keep shortcuts within the current browser tab. Scope table results to both the selected workflow and the signed-in requester, including for admins; the general Requests page retains its existing visibility rules. New request opens an in-page form fixed to the selected published workflow. Respect creation permissions and preserve deep-link/reload behavior.
